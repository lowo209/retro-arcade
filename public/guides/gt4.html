EXPERIMENTAL / PS2 WEB RECOMP

Build the next lap.

A disc is the starting point.

GT4 needs a browser build generated from your own exact disc edition. The supplied ISO is US; upstream’s demonstrated GT4 release is PAL. Your edition must be compiled and tested separately.

On this computer

WSL is not installed. CMake, Ninja and clang were not available on PATH. No browser build has been produced. Gameplay, sound, speed and multiplayer are unverified.

1. Prepare the Linux build tools

Open docs/GT4.md in this project in VS Code. It contains the complete Windows 11 / WSL2 instructions and the exact upstream command shapes. WSL2 + Ubuntu is a practical route for the Linux tools; upstream does not document a native Windows build.

2. Build your own disc

Use the official PS2 Web Recomp repository and its scripts/port.sh. The build process translates game machine code to WebAssembly. Keep its generated files private.

3. Connect the browser build

Copy the whole successful web build into private/gt4/web/. Its ps2web.html, JavaScript, WebAssembly, data, workers and supporting files must stay together. Set your disc path in ignored private/local.json. The supplied disc is already referenced there.

4. Try it in Chrome

Return to GT4 and recheck files. The server supplies the cross-origin isolation headers and byte-range streaming required by upstream. WebGPU is needed for useful racing performance. A successful build and a loaded page still need actual race, input, audio, save and multiplayer testing.

No game downloads, video substitute or external native game launcher is used.

BROWSER HELP

Restore game graphics.

The player needs WebGL, your browser’s graphics interface. If the browser cannot create a graphics context, every game using this player can fail before it starts. Replacing the game disc or BIOS will not restore browser graphics.

In Firefox

  1. Open Firefox’s Settings and search for Performance.
  2. Uncheck Use recommended performance settings to reveal the hardware acceleration option.
  3. If Use hardware acceleration when available is off, turn it on.
  4. Fully close and reopen Firefox, then retry the game.

If acceleration is already on or the option is unavailable, a graphics driver problem may be involved. Check Mozilla’s graphics troubleshooting guide. Restart after installing a driver update.

Mozilla documents the setting and required restart in Firefox’s performance settings.

Try another browser

Open this same local address in an installed Chrome or Edge browser and try a game. If that browser can create a WebGL context, it can use the existing game files. Saves and custom controls are stored separately in each browser.

If it still fails

Keep the detailed error shown by the player. In Firefox, about:support has a Graphics section that can explain why WebGL is unavailable. Share the WebGL failure reason when asking for help.
